  - 理想値は `3D RMSE = 0 mm`, `Z RMSE = 0 mm` です。
- `angle_only`

  - 理想値は `角度 RMSE = 0 deg`, `角度 MAE = 0 deg` です。
- `base_anchored`
  - 従来方式です。互換確認のため残していますが、主判定には使いません。

## 主結果

用語:

- `Base`: base カメラ観測の座標
- `Aux transformed`: aux カメラ観測を `base` 座標系へ変換した座標
- `Fused`: `base` の `x, y` と `aux` の `z` を組み合わせた統合座標

### 1. `rigid_fit` の結果

理想値は `0 mm`、`Fused - Base` は負値なら改善です。

| 指標 | 理想値 | Base | Aux transformed | Fused | Fused - Base |
| --- | ---: | ---: | ---: | ---: | ---: |
| 3D RMSE [mm] | 0.000 | 1.159 | 1.209 | 1.134 | -0.026 |
| Z RMSE [mm] | 0.000 | 0.430 | 0.356 | 0.356 | -0.074 |

読み方:

- `fused` は `base` より `3D RMSE` で `0.026 mm`、`Z RMSE` で `0.074 mm` 良くなりました。
- `aux_transformed` も十分良好で、`fused` とほぼ同等です。
- 改善量は小さいですが、「前回のように `fused` が剛体形状を壊す」結果にはなっていません。

### 2. `angle_only` の結果

理想値は `0 deg`、`Fused - Base` は負値なら改善です。

| 指標 | 理想値 | Base | Aux transformed | Fused | Fused - Base |
| --- | ---: | ---: | ---: | ---: | ---: |
| 角度 RMSE [deg] | 0.000 | 0.051 | 0.049 | 0.046 | -0.005 |
| 角度 MAE [deg] | 0.000 | 0.035 | 0.038 | 0.038 | +0.003 |

読み方:

- `fused` の角度 RMSE は今回の 3 ラベル中で最良です。
- 一方で角度 MAE は `base` がわずかに最良で、`fused` は `0.003 deg` だけ悪化しています。
- つまり回転角評価でも `fused` は少なくとも破綻しておらず、`base` とほぼ同等以上です。

### 3. `base_anchored` の結果

これは従来方式の参考値です。

| 指標 | Base | Aux transformed | Fused | Fused - Base |
| --- | ---: | ---: | ---: | ---: |
| Z変化 RMSE [mm] | 0.668 | 0.522 | 0.522 | -0.147 |
| 絶対3D RMSE [mm] | 2.251 | 1.873 | 2.430 | +0.178 |

補足:

- `base_anchored` では `fused` の Z だけが `aux` 由来なので、`z_change` は改善しても `absolute 3D` は悪化しやすいです。
- そのため今回の主判定は `rigid_fit` と `angle_only` を使います。

## 解釈

- 今回は `aux_transformed` 単体も良好で、`fused` もその良さを壊していません。
- 前回の失敗セッションでは `fused = base.x, base.y, aux.z` にした途端に剛体形状が崩れましたが、今回は同じ統合則でもその問題が出ていません。
- したがって今回の主因は「統合則が必ずダメ」ではなく、「校正結果や撮影条件が悪いと統合則の弱さが露出する」と見るのが自然です。
- 逆にいうと、今回の結果だけで「統合すると大幅に良くなる」とまではまだ言えません。改善量はかなり小さいためです。

## 結論

- 結論として、今回の `0-30 deg` 評価では座標統合は成功です。
- 主評価では `fused` が `base` を悪化させず、`rigid_fit` では `3D RMSE -0.026 mm`, `Z RMSE -0.074 mm`、`angle_only` では `角度 RMSE -0.005 deg` でした。
- ただし改善はごく小さいので、現時点の言い方としては「失敗ではない。わずかに改善した」が最も正確です。
- 次に確認したい点は次の 2 つです。
  - 同じ手順で別日・別撮影でも再現して同傾向が出るか
  - runtime の `fusion_trace.csv` 評価でも `fused` が `base` を悪化させないか
