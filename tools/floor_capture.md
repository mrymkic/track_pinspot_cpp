# 高さ固定・水平移動による床校正の撮影

台座に取り付けたチェッカーボードを、同じ基準点の高さを保ったまま左右・前後へ移動して撮影します。基準点の3D位置と実測高さを保存し、後で床に平行な座標系を求めるための撮影ツールです。

## この実機の設定

- 白黒のマス：横10 × 縦7
- 検出する内側コーナー：横9 × 縦6
- 1マス：22mm（2026-10-06に再測定）
- base：`000522521612`
- aux：`000535121612`（上下逆さま）
- 同期役割は接続端子から自動判定。現在はauxがMASTER、baseがSUBORDINATE。

設定は [`floor_capture_config.json`](floor_capture_config.json) にあります。高さは未測定のため `null` にしてあり、起動時に入力します。

## 起動

このPCの64-bit Pythonに `numpy`、`opencv-python` または `opencv-python-headless`、標準GUIの `tkinter` が入っていること、`build_2cam_x64` に `k4a.dll`、`depthengine_2_0.dll`、`export_kinect_rig_calibration.exe` があることを確認します。既存のKinectアプリを終了してから起動してください。

基準点を先に画面で確認する場合：

```powershell
.\capture_floor.cmd --preview-only
```

画面の黄色い `REF 0` が指す内側の交点に印を付け、床からその交点までの**鉛直方向の高さ**を測ります。ボード正面から見た左上の内側交点を基準にする場合、外周から横・縦にそれぞれ1マス（22mm）入った交点です。必要に応じて下記のA/Bキーでコーナー順を反転し、両画面の黄色の表示を同じ印に合わせてください。`REF 0` は検出順に付くため、撮影画面で実際に指している点を確認します。

撮影を始める場合：

```powershell
.\capture_floor.cmd
```

高さをmmで入力すると撮影画面が開きます。高さは台座の上端やボードの外枠ではなく、印を付けた内側の交点までの距離です。`--height-mm 実測値` で直接指定することもできます。

## 画面の操作

| キー | 操作 |
| --- | --- |
| C / Space | 現在の画像ペアを保存 |
| A | auxのコーナー順を反転 |
| B | baseのコーナー順を反転 |
| Q / Esc / ウィンドウを閉じる | 終了 |

キー操作は撮影画面にフォーカスを合わせて行います。A/Bは最初の保存前に使い、**両方の黄色いREFが同じ印付きの交点を指すこと**を確認してください。最初の保存後はコーナー順を固定します。変更する場合は新しい撮影セッションを始めます。

auxは画面上で180度回転して正立表示します。保存する画像と3D座標は実機の元の向きで記録し、実機のカメラ校正値と対応させます。

## 撮影の進め方

1. 基準点に印を付け、床からの高さを測る。
2. 台座の高さとボードの傾きを固定する。
3. 両方のカメラに格子全体が見え、画面の両方が `OK` になった状態で静止する。
4. Cを押して1組保存する。
5. 左右・前後に位置を変え、静止して保存を繰り返す。

**一直線に並ばない3か所以上**で撮影します。面内に広く分布した位置を使い、各位置で複数組撮ると、後で高さのばらつきを評価できます。同じ位置で何枚撮っても、床の向きを求めるための位置の広がりにはなりません。

格子が見つからない、再投影誤差が設定値を超える、画像が古い場合には保存しません。フレームの対応付けは時刻の差を直接確認し、1フレーム分のずれを同期位相だけで許容する処理にはしていません。

撮影中は両カメラの露光を同じ手動設定に揃えます。終了時に元の露光設定へ戻します。暗すぎる場合は設定の `manual_exposure_usec` を調整してください。

## 保存されるもの

```text
floor_calibration_images/<日時>/
  session.json
  rig_calibration.json
  base/0001.png
  aux_color/0001.png
  base_depth/0001.png
  aux_depth/0001.png
  captures/0001.json
```

- `session.json`：実測高さ、格子寸法、基準点、シリアル、同期役割、保存枚数。
- `rig_calibration.json`：その実機・撮影モードで取得した内部校正とcolor→depth変換。
- カラーPNG：注釈や表示回転を加えない元画像。
- 深度PNG：16-bit、値の単位はmm。
- 各組のJSON：フレーム時刻、同期誤差、検出コーナーの元画像座標、ボード姿勢、両カメラでの基準点の3D位置、aux→baseの変換。

撮影データはGit管理から除外しています。床への変換行列の推定と追跡座標への適用は、この撮影データを使う次の工程です。

## 接続・保存の確認

```powershell
.\capture_floor.cmd --check-devices
.\capture_floor.cmd --smoke-test 5
```

`--smoke-test` は格子検出や高さ入力を要求せず、ハードウェア確認用の画像を1組保存します。`smoke_...` のフォルダと `dataset_kind=hardware_smoke_test` で実際の床校正データと区別します。`--preview-only` は画像を保存しません。
